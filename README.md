# ✨ The Bodi Genie (@the_bodi_genie) — Luxury Aesthetic & Laser Clinic

A high-performance, editorial digital presence built for **@the_bodi_genie** on Instagram. Designed with a luxury obsidian-and-gold aesthetic, micro-interactions, Framer Motion animations, and an interactive online booking concierge.

---

## 🌟 Key Features

1. **UX/UI Pro Max Interface**
   - Obsidian dark mode with champagne gold accents (`#CFA868`, `#DEC293`)
   - Editorial typography with Cormorant Garamond headings & Plus Jakarta Sans body
   - Custom glassmorphism cards with backdrop blur & gold edge lighting

2. **Interactive Draggable Before/After Transformation Slider**
   - Real-time comparison slider with touch and mouse drag capabilities
   - Clinical metrics breakdown: average waist reduction, satisfaction rate, and protocol timelines

3. **Multi-Step Interactive Booking Engine (`BookingModal.jsx`)**
   - **Step 1: Protocol & Add-ons**: Choose from treatments (360° Cavitation, Diode Laser Hair Removal, Brazilian Lymphatic Sculpt, Colombian Maderotherapy, HIFEM Core) with live price updates
   - **Step 2: Interactive Date & Slot Picker**: Select next-available calendar days and morning/afternoon/evening slots for Stafford clinic
   - **Step 3: Client Details**: Input contact info, Instagram handle, and targeted body zones
   - **Step 4: Instant Confirmation & Celebration**: Confetti animation, generated booking reference (`BG-XXXXXX`), downloadable `.ics` calendar invite, and direct WhatsApp sync

4. **Curated Instagram Showcase (@the_bodi_genie)**
   - Authentic Instagram profile header with follower counts, bio, and verified badge
   - Animated story highlights carousel with full-screen interactive story viewer
   - 6-post media feed with like toggles, reel badges, comment counters, and expand-to-preview modal

5. **Clinical Protocol Architecture**
   - The 4-step client journey (Body Mapping -> Cavitation -> Brazilian Lymphatic -> Maintenance)
   - Categorized service menu with interactive clinical details modal
   - Client reviews with verified handles, 5-star ratings, and reduction badges
   - Smooth FAQ accordion with animated height transitions
   - Stafford private clinic location (Gainsborough Works, Saint Patrick's St, Stafford ST16 2PN)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
